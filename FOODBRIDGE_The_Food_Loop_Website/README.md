# FOODBRIDGE — THE FOOD LOOP

A beginner-friendly vanilla HTML/CSS/JavaScript recreation of the Foodbridge interface shown in the supplied screenshots.

## Included features
- Live surplus food feed with filters/search
- Surplus donation form
- Fresh-human vs animal-feed routing logic
- GPS capture
- Google Maps direction links
- Interactive map using Leaflet + OpenStreetMap
- Impact statistics
- PyCharts-style analytics using Chart.js
- QR generation and pickup verification
- Gamified donor leaderboard
- Team section
- Annam Dhutha AI-style chatbot UI
- Responsive desktop/mobile design
- No backend required for the demo; data is kept in browser memory

## Run in VS Code
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.

## Important
This is a working frontend/demo. For a real hackathon production system, connect:
- Firebase/Supabase for authentication + database
- Google Maps JavaScript API for a true Google map
- A secure backend for QR tokens
- A real AI API for Annam Dhutha AI
- Cloud storage for donor/food photos
- Role-based accounts for donor, NGO, volunteer and farmer
